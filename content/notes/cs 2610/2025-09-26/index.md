## Network Security Tools
- Firewalls
  - Network-Based
    - Hardware and/or software that controls network traffic
    - Could be dedicated device 
    - Firewalls often provide NAT and VPN Capabilities
    - Packet Filter
    - Stateful packet Filter
    - Application layer gateway or proxy
  - Host-Based
    - Modern OS have built-in host-based Firewalls
    - Third-party vendors
    - End point 
- IDS
  - Signature based approach
  - Anomaly detection approach
- IPS
  - Identifies and blocks packets
