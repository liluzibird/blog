## User Goal Techniques: Specific steps
1. Identifyall potential users for the new system.
2. Classify the potential users in terms of their functional role
    - Ex. shipping, marketing, sales
3. Further classify potential users by organizational level
    - Ex. operational, management, executive
4. For each type of user, *interview* them to find a list of specific goals they will have when using the new system
    - Start with current goals, then imagine new functionality that would add value.
    - Use verb-noun phrasing
        - Add customer
        - Update order
        - Produce report
        - ...
5. *Create* a list of prelim use cases organized by user
6. Look for duplicates with similar use case names resolve inconsistencies
7. *Identify* where different types of users need the same use case
8. *review* the completed list with each type of user and then with each type of user and then with interested stakeholders
