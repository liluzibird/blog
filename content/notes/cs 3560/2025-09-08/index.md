## RMO Existing Application Architecture
- Supply Chain Management (SCM)
    - 5 y/o; Java/Oracle
    - Tradeshow system will interface with SCM
- Phone/Mail order system
    - 12 y/o; Visual Studio/MS SQL
    - Reached capacity; minimal integration
- Retail Store System (RSS)
    - Older package solution; minimal integration
- Customer Support System (CSS)
    - Web based system; evolved over the years, minimal integration

    Rather than incremental updates, RMO plans to replace the new Consolidated Sales and Marketing System (CSMS)

- Once information is added to databases, all related subsystems and services should also be linked to it and automatically be updated.
    - Example: Bronconame changes, gets updated in Canvas, Enrollment, Admissions, BRIC, etc
